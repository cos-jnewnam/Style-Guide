Scottsdale Style Check

A button for Chrome and Edge that checks a web page against the Scottsdale style guide and highlights anything to fix. It only looks at the page you are on, and nothing leaves your computer.

  • Install it (one time)
  • Check a page
  • Get a new version
  • If something goes wrong

Install it (one time)

This takes about five minutes. You need Chrome or Microsoft Edge.

1. Download

Download Scottsdale Style Check

This always gets the newest version.

2. Unzip it to a folder you will keep

  1. Open your Downloads folder.
  2. Right-click scottsdale-style-check.zip and choose Extract All.
  3. Change the location to your Documents folder, then choose Extract.

You now have a folder called scottsdale-style-check in Documents.

Keep this folder. The browser runs the check from it. If you delete or move it, the button stops working.

3. Turn on Developer mode

ChromeEdge
Type chrome://extensions in the address bar and press Enter. Type edge://extensions in the address bar and press Enter.
Turn on Developer mode in the top right corner. Turn on Developer mode in the left sidebar. If you don't see the sidebar, make the window wider.

If there is no Developer mode switch, or it is grayed out, stop here and contact the web team.

4. Add the extension

  1. Choose Load unpacked. It appears after Developer mode is on.
  2. Go to Documents, select the scottsdale-style-check folder and choose Select Folder.
  3. Scottsdale Style Check now appears in your list of extensions.

5. Pin the button

  1. Select the puzzle piece icon next to the address bar.
  2. Select the pin next to Scottsdale Style Check.

The dark blue button with a white check mark now stays next to the address bar.

Check a page

  1. Open the page on ScottsdaleAZ.gov or ScottsdaleLibrary.org. Use the live page, a preview, or the page after you save it. The Sitefinity editing screen itself is not checked.
  2. Select the check button, or press Alt + Shift + S.
  3. Problems are highlighted on the page and listed in a panel on the right.

Reading the highlights

  • Solid red is an error. It breaks the style guide. Fix it.
  • Dotted amber is a review. It might be a problem. Read it and decide.
  • Hover over a highlight to see what is wrong.

Using the panel

  • Select an item in the list to jump to it on the page. Previous and Next step through them in order.
  • The red and amber buttons at the top show or hide errors and reviews.
  • Ignore hides one item until the next check. Use it when a review item is fine as written.
  • Copy report copies a list of every item, with the words around it and the part to fix in [brackets]. Paste it into an email or Teams to send to someone.
  • Close, or selecting the button again, removes every highlight. The page goes back exactly as it was.

The number on the button shows how many items were found. Red means there are errors, amber means only reviews, and a green OK means the page is clean.

Read the full Scottsdale style guide (PDF).

Get a new version

The web team will let you know when there is a new version.

  1. Download the newest version.
  2. Unzip it to Documents the same way as before. When Windows asks, choose Replace the files in the destination.
  3. Open chrome://extensions or edge://extensions.
  4. On the Scottsdale Style Check card, select the circular reload arrow.

If something goes wrong

What you seeWhat to do
A red ! on the buttonThat page can't be checked. Browser pages, settings pages and the extension store are blocked. Try a ScottsdaleAZ.gov page.
Nothing happens when you select the buttonRefresh the page and try again. If it still does nothing, open the extensions page and select the reload arrow on the Scottsdale Style Check card.
The browser warns about developer mode extensionsThat is expected for this tool. Choose to keep the extension.
The extension says the folder is missingThe folder was moved or deleted. Do the install steps again.
Something is flagged that is correctSelect Ignore, and let the web team know so the check can be improved.
